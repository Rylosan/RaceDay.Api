# Part 3 – RaceDay Application

This folder identifies the Part 3 submission.

## Project
RaceDay is a full-stack event management application built using ASP.NET Core Web API, ASP.NET Core MVC, SQL Server, Azure Blob Storage and Docker.

## Source Code
The complete application source code is organised in the following folders at the repository root:

- `RaceDay.API/` – Backend API
- `RaceDay.Web/` – MVC frontend
- `RaceDay.API.Tests/` – Automated tests
- `Database/` – Database scripts
- `Documentation/` – Project documentation
